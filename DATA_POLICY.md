# Data Policy

This public V3 release is for methods, project code, schemas, synthetic examples, limitations, and the project log. Other youth participant data is handled privately.

The telemetry example uses synthetic data. Except for the Leo case explicitly authorized below, no participant videos, individual results, private reports, contact details, or identifiers may be added to the public repository, Issues, pull requests, notebook outputs, or commit history.

A replacement player ID does not establish anonymity. Check filenames, dates, source-frame references, body/motion patterns, and links that could reconnect telemetry to a person. A skeleton overlay does not anonymize a video. Keep other raw and annotated media private.

Git ignore rules reduce accidental additions but are not a security boundary. Review every staged file and the commit history before publishing. Third-party code, model weights, images, logos, and media require an appropriate license or specific publication permission; do not assume the project's MIT license grants those rights.

## Specific publication exception: Leo coaching case

The owner expressly authorized publishing the supplied Leo demo. Selected clips, still frames, first name, session dates, report-based scores, and an archived overlay are included in `examples/leo-coaching-demo/`. This exception applies only to those supplied assets; the original recordings and private review PDF are excluded. Media and likeness rights are not granted by the MIT code license. The case is not a public-script validation dataset or an automatic-scoring demonstration.
