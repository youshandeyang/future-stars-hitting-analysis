# Data Policy

This public V3 release is for methods, project code, schemas, synthetic examples, limitations, and the project log. Real youth participant data is handled privately and is excluded from the release.

Public examples in this release use synthetic data only. No participant videos, individual results, private reports, contact details, or identifiers may be added to the public repository, Issues, pull requests, notebook outputs, or commit history.

A replacement player ID does not establish anonymity. Check filenames, dates, source-frame references, body/motion patterns, and links that could reconnect telemetry to a person. A skeleton overlay does not anonymize a video. Keep raw and annotated media private.

Git ignore rules reduce accidental additions but are not a security boundary. Review every staged file and the commit history before publishing. Third-party code, model weights, images, logos, and media require an appropriate license or specific publication permission; do not assume the project's MIT license grants those rights.
