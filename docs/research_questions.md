# Research Questions

1. Which 5-8 movement measurements are stable enough for repeated home video?
2. How much does camera angle / height / distance affect each measurement?
3. How should Contact and other swing events be labeled consistently?
4. When Side and Back views disagree, how should the evidence be interpreted?
5. Which differences between Tee and Toss are repeatable for the same player?
6. Which practice changes produce repeatable movement changes at retest?
7. Which movement changes are associated with improved contact quality or performance?
8. How can AI summarize evidence without turning uncertainty into false confidence?
9. What parts of the method can a parent reproduce without a coach present?
10. Which metrics should be removed because they are too noisy or not useful?
