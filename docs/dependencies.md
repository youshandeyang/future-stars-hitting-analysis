## Fonts embedded in the family checklist PDF

The PDF embeds DejaVu Sans Regular/Bold subsets with the original Bitstream Vera/Arev license metadata retained in the font streams. See https://dejavu-fonts.github.io/License.html.

Helvetica is an unembedded standard PDF resource. No standalone font files are redistributed in this repository.
