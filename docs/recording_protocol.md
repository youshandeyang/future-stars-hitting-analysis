# Recording Protocol

Goal: make home video repeatable enough for comparison.

For the no-code family workflow and safety checklist, start with [the English guide](family_swing_checklist.md) ([one-page PDF](Future_Stars_Family_Swing_Checklist_EN.pdf)). A single fixed side view is a practical starting point. The optional Phase II four-video set below is captured in separate takes, not synchronized 3D evidence.

## Standard four-video set
1. Side Tee
2. Back Tee
3. Side Toss
4. Back Toss

## Minimum guidance
- Keep the whole body, bat, plate area, and some early ball flight in frame.
- Keep the camera fixed during a set.
- Avoid digital zoom changes between baseline and retest.
- Record several swings, not just the best swing.
- Try to reproduce camera height, distance, and direction at retest.
- Save the original video before any cropping.

## Current research question
How much do small camera-position changes affect the 2D angles we measure?

## Standard baseline and retest set

Record 8-10 comfortable swings for the baseline and again at retest. Review 5-10 swings, including ordinary attempts rather than only the best one. This is a practical recording protocol, not a validated sample-size threshold. Match the drill, equipment, and camera setup at retest.

One safe fixed side view is the minimum. Four-view clips are optional separate takes for the expanded workflow; they do not constitute synchronized 3D measurements. Keep the family checklist's camera-protection, adult-supervision, fatigue/pain, and privacy precautions when using the fuller guide.
