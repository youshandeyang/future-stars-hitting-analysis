# Six-Category Scoring Rubric

Phase I uses six coaching categories:
1. Load & Preparation
2. Lower-Body Sequencing & Posture
3. Separation & Connection
4. Barrel Path & Through-Zone Extension
5. Hand / Wrist Control
6. Balance / Finish / Repeatability

The score is a coaching summary, not a medical diagnosis or an automated talent score.

Phase II goal: support each score with visible examples or simple measurements where possible, while keeping Vincent's coaching judgment explicit.

The starter specifies category names, but does not supply calibrated scoring anchors, inter-rater agreement results, or an automatic score-to-angle mapping. These need to be defined and evaluated before scores can be treated as reproducible measurements.
