# Examples

- [Leo coaching case study](leo-coaching-demo/README.md): family-authorized real footage, Vincent's baseball coaching observations, AI-assisted reporting context, six-category *human-reviewed* score comparison, and a separately labeled archived overlay. Not a reproduced run of the public Python script or a programmatically calculated coaching score.
- [Synthetic telemetry CSV](../data/sample_telemetry.csv): illustrative schema data, not a real-player measurement or actual script output.

The primary goal of the case is to demonstrate a low-cost video-review → practice → retest **coaching process**, rather than independent software accuracy. See [project roles and evidence](../docs/project_roles_and_evidence.md) for the responsibility and verification boundaries.

Only the specifically authorized Leo demo media is included. Other participant media, reports, and telemetry remain private. A skeleton overlay is not anonymization. See [data policy](../DATA_POLICY.md).
