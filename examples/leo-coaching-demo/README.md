## Interpretation limits

The six-category baseline was mapped retrospectively. The +4 difference is an ordinal coaching-rating change, not a calibrated physical gain or causal effect of the drills. Baseline CQS is 80/100; retest CQS is unavailable. The report covers multiple views and swings; the two selected side-tee excerpts alone do not establish the complete assessment.

Phase labels and pairing are approximate. The original extraction timestamps and frame selection have not been independently re-verified here. Starting both clips together does not synchronize contact frames.

The archived overlay was transcoded to H.264 for browser playback, without rerunning pose detection or changing its displayed measurements. Its original runtime version and accuracy are unverified. It is not proof of the current public script's behavior. No new code run, generated telemetry, automatic score, or independent Vincent development contribution is claimed.
