# Contributing

Constructive criticism is welcome.

Good contributions include:
- Camera-placement tests
- Measurement-repeatability tests
- Better event-label definitions
- Bug fixes
- Missing-data / occlusion handling
- Reproducible plots
- Youth-friendly report ideas
- Evidence that a current metric is unreliable

Please keep claims proportional to the evidence.

Do not submit identifiable youth media or personal information in Issues or pull requests.

Keep public examples synthetic. Do not include private source filenames, participant telemetry, notebook outputs, or third-party assets without appropriate rights.
