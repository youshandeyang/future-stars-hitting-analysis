# Contributing

Constructive criticism is welcome.

Good contributions include:
- Camera-placement tests
- Measurement-repeatability tests
- Better event-label definitions
- Bug fixes
- Missing-data / occlusion handling
- Reproducible plots
- Youth-friendly report ideas
- Evidence that a current metric is unreliable

Please keep claims proportional to the evidence. Distinguish contributions to **coaching goals, recording workflow, interpretation, system requirements, AI-generated code, and third-party software**. Do not imply a student wrote or validated code just because they led the project. Clearly identify the tests actually performed; simulated or mocked tests do not demonstrate biomechanical accuracy.

If you propose a new measurement or improvement, please include the filming setup, reproducible method, limitations, and how the result could be checked. Review [project roles and evidence](docs/project_roles_and_evidence.md) before suggesting changes to public-facing claims.

Do not submit identifiable youth media or personal information in Issues or pull requests.

Use synthetic examples for public code and telemetry demonstrations by default. The existing [Leo coaching case](examples/leo-coaching-demo/README.md) is a separately authorized exception for selected media and coaching material; it is **not** a code-validation dataset or license for reuse. Do not add further participant data or third-party assets without specific permission and review of privacy and rights. See [data policy](DATA_POLICY.md).
